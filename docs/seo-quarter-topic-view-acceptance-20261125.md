# 季度进度与话题贡献展示验收

本次补齐已批准 v9 的两个展示接缝，不改1600确切原词、主国语种、原任务、正式计划、报告模板或调度。季度建设进度按原事实互斥展示：已有真实公开页优先；原制作任务已制稿、审稿或发布核验为制作中；正在研究单列研究中；其余制作任务只有列入真实 `scheduled/reviewed` 计划才为已排期。仅有URL、dueAt、ready状态或研究计划不授已排期/制作资格。已有公开页也不表示其后续翻新、优化任务全部完成。

话题列表与总览共用已保存、同统计及对比窗口的实际页面贡献证据。按明确本站话题、国家、语言、指标和来源分别列上期、本期、增减和实际页面链接；不把父子话题、国家、来源切片相加成全站总量。GA4页面会话贡献不是整段去重的话题用户/全站会话；GSC点击及曝光分列。冲突观测、错窗口、原生异时区及错来源不参与此投影。

同一URL/指标/国家语言/窗口/来源是一条页面观测，多个方向或话题引用不能增加计量。相同观测出现数值冲突则全部留出展示；出现多个明确话题归属时不强指给任一话题，但模块视角仍仅计一次。模块也有冲突时列“模块待核”，原证据和历史不改。俄语市场标签仅为译文观察，不授独立挖词/源文规划资格。

现有注册及首次付费只读模型尚不含可靠的逐话题、同批用户归因关系。话题表明确显示“暂无可核归因”，不将全站数分摊到话题，不按页面访问推定注册或付费，也不将缺源填0。本次不因此新增采集、Google写入或产品埋点改动。后续可靠来源接好后仍须按同批合资格自然访客和原注册批次的720小时首次付费定义消费，不能直接用sessions或newUsers作分母。

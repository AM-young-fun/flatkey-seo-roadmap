# 旧文轮查历史数据复用

旧文候选入口回看最近90个已结束GSC自然日，按同站、原国家和同一属性选择最近具备至少4组同星期配对的7日窗口。近期孤立完整日不遮住既有可比窗口。仍只消费已保存complete记录，不把部分记录改为完整，不把缺页补零。

候选和覆盖分别返回实际比较截止日及最新来源日；偏旧数据保留historical标记及原因。旧文研究不因四日新鲜度门槛自动失效，正式制稿仍需当期原词SERP、线上页面和3C复核。其他优先榜及效果统计保留原规则。

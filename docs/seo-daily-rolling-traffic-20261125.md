# 日常滚动7日与固定验收周

日常总览和新生成日报的目标段使用截至实际取数时刻、最新已完整结束的7个洛杉矶自然日，明确列区间、距3000差额及与前一日滚动区间的变化。按IANA时区和真实asOf确定LA午夜：冬令时北京时间16:00、夏令时15:00附近会变化，不能按北京时间日期或写死小时切分。历史日报回补至其实际统计日，不借用更晚的源日。

该观察使用既有`record_traffic`正常保存链上的新`whole_interval_scalar`证据：Flatkey属性541304395、原metadata为LA、官网及控制台三个生产hostname、sessionDefaultChannelGroup=Organic Search，取无日期维度的整段sessions标量及真实requestBody SHA、来源时刻和UTC起止。不由日桶求和构造权威标量，不伪造days，不把无结果当0；新源未齐时保持缺口，不回退成旧固定周数值。前一日区间可以本次正常取数，但observedAt仍为本次真实采集时刻，不能冒称昨日已采。旧native_days、utc_hours及原始历史证据按各自既有事实继续读取。

源采集只沿原`server-seo-daily.cjs`添加Flatkey一个完整区间标量，不新增job、不扩其他站点/Google配置/付费。旧固定周采集与日报其他模块保持原流程。正常归档及失败读回沿既有CAS/idempotency规则，不盲重试。

周报归因、关键词窗口和固定LA周四至周三完全不改。季末流量验收仍独立读取LA2027-01-28至02-03；截止后有利的滚动7日不能替代该验收。旧已归档、已审核、已发送正文及hash不重写。新投影有显式`rolling7day-v1`标签，旧快照缺此字段仍按原固定周语义展示。

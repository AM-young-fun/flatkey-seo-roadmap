# SEO 站点语言与执行规则

国家是搜索数据的筛选条件，内容语言是页面的制作和发布条件。任务单、审批单和发布回执分别保存站点、国家、内容语言及目标 URL。

| 站点 | 本轮核实的制作语言 | 2026-11-12 公开证据 |
|---|---|---|
| Flatkey 官网 | 美国英文、日本日文、巴西葡语、西班牙西语 | [官网](https://flatkey.ai/) 的语言入口和 hreflang 含对应四个市场。此处是本轮 SEO 配额，官网其他现有语言继续正常运行。 |
| RackRate | 英文 | [首页](https://rackrate.org/) 返回 HTTP 200，HTML 声明 en，本轮未找到其他语言入口。 |
| ModelFit | 英文 | [首页](https://modelfit.cc/) 返回 HTTP 200，HTML 声明 en，本轮未找到其他语言入口。 |
| JEV LLM | 英文 | [首页](https://www.jev-llm.com/) 返回 HTTP 200，HTML 声明 en，本轮未找到其他语言入口。 |
| MochiChatbot | 英文、日文、巴西葡语、简体中文 | [首页](https://www.mochichatbot.com/) 的 hreflang 列出 en、ja、pt-BR、zh-CN。制作前还需核对目标页面是否有相应路由。 |

四国四语选词及每国源文配额只用于 Flatkey 官网。集群站的关键词、博客、落地页、旧页优化和技术修复使用该站已支持的实际语言。英文站可以按西班牙或日本筛选 GSC，产出依然使用英文。现有页面优化时先核对实际页面语言，站点有多种语言时选择与目标 URL 相符的语言。

定时任务领取时先按站点查允许语言，再核对路由、sitemap 和 hreflang。语言证据不全、目标 URL 语言不匹配或用户指定的语言不受支持时，将任务标记待核实并记录证据、阻塞和下一步。新增语言需要先核对生产支持，再同步更新平台站点语言配置和定时任务规则。

平台表单和后端校验共用 `WORKFLOW_SITE_LANGUAGES`。已保存的历史记录保留原始国家和语言，处理新版本时以本规则核验。定时任务送审前再次核对测试版本的页面语言，避免因国家筛选或 hreflang 误指发布错误语言。

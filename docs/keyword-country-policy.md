# 关键词市场与付费排名规则

更新：2026-11-10。此规则只改变未来查询范围，不删除历史排名、GSC 数据或词库。

每个关键词必须有明确的主目标国家与本地语言：US/en、JP/ja、BR/pt-BR、ES/es-ES。不能从词语的文字、源文章语言或已有跨国排名直接推断需要付费查询的国家。额外国家需要独立研究理由。

批准工作流中的关键词任务时，将关联的 `keywordId`、站点、国家、语言与证据写入 `KeywordSourceRow` 的 `SEO_MARKET_ASSIGNMENT` 来源。已有主国家不会被后来的表格同步覆盖；另一个经审核市场保留为有理由的 secondary market。缺少 `keywordId` 或未明确国家的词留在待核实队列。

未来 DataForSEO 报价、样本与常规批次只对这些国家去重查询。同一查询、国家、语言、桌面 Google 配置、期次共享一次结果，多站点可复用。语言与设备由固定市场配置绑定；同一期次的数据库唯一账本防止重复扣费。

自有品牌 Flatkey、RackRate、ModelFit、MochiChatbot、JEV LLM（包括空格、连字符及域名写法）不进入付费查询。OpenAI、Claude、Gemini、DeepSeek 等相关模型/供应商名称保留。旧品牌数据仍可查看。

业务优先门槛是目标国家月搜索量 ≥10 且 KD＜30。低量、高意图或战略词必须说明具体例外；未知 KD 不能按 0 处理。筛选优先级不是删除已有词库的理由。

新批次冻结 `primary-country-nonbrand-v1` 策略与市场证据。旧四国广播账本不再提交尚未发送的付费任务；已取得 provider task ID 的任务仍可免费回查。不要把未查询、失败、市场范围改变当成掉榜。范围改变后的趋势应建立新基线，固定词池与动态发现池分别解释。

自动付费开关保持关闭。代码改动不会修改生产授权、预算或触发付费请求。

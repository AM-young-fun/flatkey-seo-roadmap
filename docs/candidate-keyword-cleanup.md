# 候选词筛选与批量移除

在「关键词明细 → 词库分类 → 候选词」点击「预览候选词筛选」。系统按业务无关、竞品服务商品牌、低质量记录三类生成建议，默认勾选建议移除项，可按原因或词文本筛选并调整勾选。

点击「移除所选」后，仅将 Flatkey 当前仍启用的 `RESEARCH` 记录改为 `ARCHIVED`，保存逐词原因、时间与本轮审计。全局关键词和历史观测不删除，可通过「数据管理 → 动态清理与恢复」恢复到候选池。正式词、其他网站和模型保护词不参与本操作。预览后词库变化需重新预览。

筛选只提供可复核的建议：模型名、GPU 名称、有效技术参数、多语言查询和有明确业务意图的自然问句保留，不凭未知或零搜索量移除。服务商竞品包括 OpenRouter、Portkey、LiteLLM、RunPod、Vast.ai 等；Grok 与 Groq 分别处理。Vercel AI SDK 的明确接入/兼容配置需求保留。

`GET /api/keywords/candidates/cleanup` 返回候选快照、分类、逐词原因及 `stateHash`。`POST` 传入 `keywordIds`（1–5000 个）和 `expectedStateHash`，在站点导入锁与数据库事务内检查后应用。入口沿用网页登录鉴权，导入密钥和导出密钥均无权调用。

批量写入和 `KeywordCurationAudit` 记录在同一个事务，任何错误均回滚；客户端不凭请求发出就声称移除成功。清理完成可下载 JSON 回执，包含审计编号、逐词原因、处理数量和剩余数量。

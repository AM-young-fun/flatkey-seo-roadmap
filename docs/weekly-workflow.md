# SEO 词库与周报工作流

2026-10-19，替代每月1日/16日和每周重新抓两期排名的旧方案。

## 当前执行状态

用户于2026-10-19授权本轮DataForSEO付费采集，并明确本轮结束后隔两周周二继续自动执行。排名付费由线上「数据管理 → 隔周自动更新」控制，先核对余额、范围及预算再开启；无需另去Vercel修改付费环境变量。每日日检和长期周报桌面自动化仍暂停，当前授权不恢复它们。历史已存的38词四国结果不是新一轮全量结果。

Flatkey使用America/Los_Angeles时区，本期到北京时间2026-10-20 15:00才结束。现阶段只能保存明确标记的草稿。排查可使用已结束的同星期区间（本次10-13至10-17对比10-06至10-10），不得拿本周阶段累计与上周完整七天计算环比。

## 新词入口与日常维护

主要入口是三张钉钉协作表，以及 DataForSEO Labs 的域名已排名词。三表仍沿用已登录的采集器，计划每天10:30检查；线上显示已保存同步状态。只写新增或真实变化，已有记录相同则跳过。旧词在表里缺行、Labs未返回、排名消失，都不因此删除词库或候选。候选、待建设、人工归档和归并记录不能被来源同步自动复活或覆盖。

Labs 仅覆盖 flatkey.ai × US/JP/ES/BR，每国最多1000条，每周期4个独立账本。RackRate、ModelFit 不在本任务内，已保存的词库及历史保留。SERP范围也只取Flatkey已有合适页面的正式词。不自动翻页；供应商截断标记原样保留，不能宣称覆盖所有域名排名词。业务无关词排除，已有词规范化去重，不创建重复身份。每个实际页面分别保存数据库位置和来源更新时间，Labs 不进入实际SERP排名标签。

新增业务相关或可能相关的词先保留为研究词，明确无关词不入库。自动关联只处理本轮新增、未人工改过的研究词：当前本站HTTPS页面HTTP200、无禁止收录指令、canonical正常，并且当前title/H1精确覆盖该业务词时，才提升为正式目标并记录独立页面审核证据。每个市场最多自动核对30个新词，每词最多3个页面；其余研究词与所有已发现页面证据保留，不强行认定为无页面，也不参加付费。语义变体不能只凭旧Labs标题或首页命中就通过。日检采集器可继续逐词核对剩余研究词。现有人工关联和排除不被改写。

正式词只有已有合适页面才加入SERP；已上线但待优化的合适页面继续监控。无合适页面的正式词保留待建设，页面就绪后加入下一轮。

## 隔周排名周期

固定北京时间隔周周二10:30，锚点2026-10-20，后续11-03、11-17、12-01、12-15、12-29。每14天一轮，个别月份三轮。旧的1日/16日账本不改写；新账本以排定日期为唯一键，同一期不能另起ID重复扣费。

顺序为 Labs 发现 → 筛选/去重/核对页面 → 冻结正式监控集合 → SERP前100。四国分别搜索，跨网站可共享完全相同的查询，每站实际命中页面独立保存。汇总按关键词去重，采用各国最佳有效自然排名；区间互斥。只有完整查过100个自然位置才可判定前100之外。未采集、失败、Google纠词及有限深度未命中都不能据此判定。

统一后台协调器由Vercel每5分钟检查是否有需要继续处理的已授权周期；这不等于每5分钟重新抓取。通常到隔周周二10:30创建新发现周期；登录管理员可以在计划前24小时内，按同一期唯一账本提前执行。本次若提前执行，仍归10月20日期，下次是11月3日，不因完成时间更改锚点，也不能明天重复扣费。Labs每次推进一个市场，SERP先回收已付费结果，再续交未提交批次。概览与管理页显示独立的本轮查询进度（仅任务元数据，采集中每30秒更新），旧的可用排名结果不代表本轮已完成。

开关默认关闭；旧配置的授权版本默认0，不因发布新代码自动获得付费权限。登录管理员经签名费用预览启用后，原子保存SERP授权版本1、单轮/月度预算及Labs连接开关。普通执行不再依赖旧`DATAFORSEO_SERP_PAID_ENABLED`或`DATAFORSEO_DISCOVERY_PAID_ENABLED`部署标记；`DISABLE_EXTERNAL_FETCH`仍是服务端紧急停止。关闭页面开关会同时停止新Labs和SERP付费提交；已付费且已知ID的SERP结果继续免费接收。余额不足、响应不明、费用超限不自动重发。每次Vercel调用有独立调度回执，记录成功不等于三张钉钉表已经拉取。

费用预览只进行免费的认证/余额查询，不提交付费任务。明确显示当前SERP上限、Labs每轮上限$1.584及SERP月度上限。发现新词后重新计算；超过已确认SERP上限时自动暂停，等待确认新费用，不静默提高预算。普通计划设置旧接口仍只能关闭；开启必须走登录管理页签名预览，令牌绑定连接、词库、配置版本、期次和费用，不能传任意日期、地址或金额。

响应不明的付费POST保存UNKNOWN，不能重发；已保存响应重放与导入重试不重新收费。新词导入批次在首次写入前冻结，续跑不能因词库已有新增而重排批次。

## 每周周报

每期周二至周一，供周四周会。周二10:30准备，18:30核对完整流量数据。Flatkey GA4时区America/Los_Angeles，周二上午北京时间上一周尚未在当地结束，不能把阶段数据作为完整周导入。只采新一期，上期直接复用已保存周报。缺失或确认错误时才补采，不重复请求上周数据。

采集周等待Labs和该周期SERP任务结束；部分返回不提前发布最终关键词环比。原任务延迟到周三完成时仍关联原账本，真实检查日期不能伪造成周一。非采集周写明“本周未安排关键词采集”，显示最近一期的日期与结果，不补零、不生成虚假本周变化。若上一周没有关键词数据，使用当前采集之前的第一期已完成实测账本对比，标明“对比第一期”、真实采集日和两期已查词数。第一期只有38词的小批范围，后续新增包含扩大采集范围首次发现的排名词，不能全归因为自然排名增长。确实没有任何历史实测时才作为首次基线，实际有排名词全部作为新增建档。

关键词周报直接读取SERP账本，不再为了周报抓两份GSC/Ahrefs均位。区间数量、去重新增、确认跌出与页面变化分别汇总。下降明细逐行显示关键词、国家、两期最佳自然排名、下降幅度及对应原/现页面；只换页面但本站最佳排名未下降的不列为流失。失败/深度不足导致的有效结果缺失不算确认流失；记录数净变化与无法核实的数量同时保留。

GA4新增用户取newUsers；注册取整周sign_up_success用户总数（去重），不是事件次数。首次来源渠道与同一批新访客顺序漏斗独立展示。“注册人数/新用户数”不是同一批新访客的真实转化率。漏斗必须按事件顺序读取，不能用独立事件人数拼凑。form_start/form_submit可能包含其他表单，不能声称覆盖所有注册方式。

大幅变化先核对站点、渠道、地区、设备，再看注册路径和实际页面证据。GSC点击变化是辅助获客证据，不能冒充实际排名或直接归因为SEO。没有同期技术日志时，不猜网络故障、埋点调整或节日原因。

## 保存流量渠道和漏斗

现有`POST /api/rankings/import`及登录会话`POST /api/seo/import`的traffic记录可附`analysis`，由`weeklyEvidenceSchema`校验，保存在WeeklyTraffic.analysis。必须为完整周，complete=true；analysis.totals.current必须与父记录人数一致，渠道去重后总人数须与两期汇总一致，漏斗按步骤递减，来源限定Google Analytics/Search Console。导入一份本周记录即可，不必重传上周。

采集器可使用已有安全导入凭据，或登录不加入主导航的`/collect`内部文件采集页；不得把凭据放入文件或聊天。每批使用稳定requestId，重复内容幂等。参考类型见`src/lib/weekly-evidence-schema.ts`。缺少有效注册事件或无完整数据的站点记缺失，不填0。历史10/6期的人工核对补充保存在版本化证据文件中，新的完整导入优先，不能用旧阶段数据覆盖新数据。

当前阶段证据使用`kind: weekly-report-draft`文件，经登录采集页保存到独立`WeeklyReportDraft`表。包含阶段累计、已结束且相隔7天的等长诊断区间、渠道和顺序漏斗、人工核对的事实及不确定项。接口不接触排名供应商，不写`WeeklyTraffic`；相同或更旧的采集时间跳过，已有正式周报时拒绝覆盖。完整周报导入后自动优先正式数据并隐藏草稿。原始渠道、地区、设备及落地页证据留在忽略提交的`.local`目录，新一期业务数据不写入公开Git仓库。

## 页面

排名概览：四国去重汇总、各国占比、真实采集期趋势、业务词库关系图。两个环形图色块及图例tooltip显示类别、数量、占比分母。移除小型跳转/说明按钮。

关键词明细：默认全部国家、关键词去重、10条/页。国家为本页筛选。取消词库来源和页面任务按钮。排名只筛四个互斥区间及“100之外”；未采集/无有效结果不混入已确认前100之外。

流量周报：先数据和渠道/漏斗/关键词图表，再原因排查与总结。数据管理展示运行计划与记录、隔周自动更新开关、三表同步和DataForSEO连接。明确区分线上Vercel执行的排名与仍依赖外部已登录采集器的钉钉、GA4；不把配置了日程当成实际执行成功。

## 费用预估

仅Flatkey按实时可监控去重词数 N 计算：四国SERP单轮保守预扣 N×4×$0.006；Labs四国每国1000条上限，4×($0.012+1000×$0.00012)=$0.528。每轮合计上限为 N×$0.024+$0.528。新增词加入后重算，未返回足量时实际费用可能较低。实际完成情况和费用以线上执行账本为准。提前执行后，页面分别显示本轮进度和下一固定槽位；后台仍保留本轮工作游标直至结束，不会在原定日重复扣费。

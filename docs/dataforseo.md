# DataForSEO 线上排名更新

现有「数据管理」页配置 DataForSEO 并手动更新；不另建目标页面。三张协作表每天同步新增和真实变化，排名建议每14天更新。双周自动付费目前未开启，不能把每天的词库日检变成每天调用收费接口。

## 首次试用范围

用户已批准 Flatkey 美国英语、最多1000条 Ranked Keywords 的一次试用。Google Labs 定价为每任务$0.012、每返回项$0.00012，不加clickstream；单轮估算上限$0.132。本系统试用累计硬预算$1，预算账本不等同于供应商实时钱包余额，不自动充值，不扩展国家或翻页。每14天一次的美国单轮上限折算月均约$0.286；实际取决于返回条数与供应商计费。报价依据：[官方价目表](https://dataforseo.com/pricing/dataforseo-labs/dataforseo-google-api)。

## 连接与执行

从 [API Access](https://app.dataforseo.com/api-access) 获取 API login/password（不同于网页登录密码），填写管理页连接表单。登录会话保护所有读写；密钥以AES-256-GCM加密存储，服务端由现有LOGIN_PWD派生独立密钥。返回信息只含配置状态和脱敏登录名，不回显秘密。更改LOGIN_PWD后需重新保存连接。凭据不进前端构建、源码、日志或导出文件；保存连接本身不调用收费API。

先点费用预览，再点标明最高费用的更新按钮。预览不发外部请求；执行固定 target=flatkey.ai、location_code=2840、language_code=en、limit=1000、organic前100、historical_serp_mode=live，禁止客户提交任意目标或扩展费用。服务端用持久requestId和预算预留防止重复扣费；同一requestId永不再发送付费POST。

响应未确认时保留UNKNOWN及预算预留，先核对供应商账单，不自动重试付费请求。结果已经收到但入库失败时，只重放已存结果入库，不再请求供应商。管理页显示每轮状态、实际成本/预留、本系统预算、匹配已有词数、待筛检候选数和是否达到返回上限。

运行记录可下载本次规范化关键词、逐页排名及待筛检候选，只允许已登录的管理会话读取。下载不含原始供应商响应、请求头或连接凭据。入库规划事务给20秒独立预算，失败保留安全错误码供排查；重放仍是零外部请求。

## 数据口径

Labs Ranked Keywords是供应商的域名排名数据库，按周更新；接口名live不代表本次实时抓Google。保存本次采集时间、实际源SERP更新时间、自然结果rank_group、真实URL和可用搜索量。没有源日期时明确未知，不用采集时间冒充；无真实声量月份信息的零量不作为“两个月无声量”的证据。来源固定为dataforseo_labs，不能伪装成GSC/Ahrefs。

默认排名概览和关键词主表使用最近一次成功完成的DataForSEO结果；两次更新之间保留该快照，展示实际采集日期，不因超过7天而清空。GSC/Ahrefs原始记录留在历史证据区，不参与默认排名。趋势图最近7天仅展示真实采集快照（含当天），首次更新前无曲线，最近7天未更新则显示无新采集，不用旧GSC均值补线。未完成批次不充当成功更新。

已有业务词以稳定身份匹配，保留正式目标、候选、模型保护和人工目标页面。供应商报告中的URL是实际检测页面，不自动替换人工目标页。新发现未知词先保留待筛检，不自动进入正式池；明确无关词拦截。原有目标本轮未检出只能标暂无排名证据，不能推断明确前100外，也不删除关键词。最多1000条是报告返回上限；截断时如实提示，不把未返回词当排名下降。数据库未覆盖的查询仍可能在Google有排名。

原始返回与规范结果保留在服务端请求记录；历史原始指标和审核证据可追溯。任何来源更新都不能重新应用固定历史审计、复活归档/归并或删除候选。

## 同词多页与核实结果

目标页面与实际排名页面分别保存，一个关键词可以有多个页面。目标页逐页检查HTTP状态、最终canonical及正文意图；每个新增匹配页都有独立证据。同次Labs采集的每个实际URL保存自己的自然名次与源SERP日期；日期不同不互相覆盖，也不把关键词摘要名次复制给其他页面。关键词摘要从最新来源日期组中取最佳名次，词数按关键词去重，页面数单独统计。

逐词页面审计支持VERIFIED（已核实匹配，含additionalPages）、NO_MATCH（查过公开目录仍无匹配页）、MISSING（明确404/410）、CONTENT_GAP（页面存在但缺少目标意图内容）、MISMATCH（页面意图错配）、REVIEW（证据不足）。NO_MATCH必须记录核查目录、页面数、时间和具体检索结论；不能把未找到页面伪造成404。CONTENT_GAP保留检查页面作为内容优化线索。缺页、内容缺口及错配只调整页面状态，关键词继续保留；本轮已有待核实词应核成具体结论，不能靠重命名隐藏未核实工作。

每个关键词只展示一个排名区间标签：前10（1–10）、前30（11–30）、前50（31–50）、前100（51–100）、暂无排名。暂无排名的说明区分未更新、本次未检出与有明确前100外证据，不能从供应商未返回推断确定排名外。

## 连接与执行

从 [API Access](https://app.dataforseo.com/api-access) 获取 API login/password（不同于网页登录密码），填写管理页连接表单。登录会话保护所有读写；密钥以AES-256-GCM加密存储，服务端由现有LOGIN_PWD派生独立密钥。返回信息只含配置状态和脱敏登录名，不回显秘密。更改LOGIN_PWD后需重新保存连接。凭据不进前端构建、源码、日志或导出文件；保存连接本身不调用收费API。

`GET /api/serp-monitor`读取连接脱敏状态、正式目标清单摘要、每月两期计划、费用预估和已有账本。`POST /api/serp-monitor`的`action:preview`只在本系统计算目标去重查询与费用，不发外部请求；`action:configure`只能将付费保持关闭。`GET /api/serp-monitor/results`返回正式目标词的实测结果及逐页证据，支持网站／地区筛选；尚未采集的范围明确待采集。

SERP使用Standard普通队列：`/v3/serp/google/organic/task_post`提交、`/v3/serp/google/organic/task_get/advanced/{id}`取回原任务，固定美国、英语、桌面端、前100自然结果，不提前在找到首个本站页面后停止。相同查询可共享一次SERP结果并分别匹配各目标网站；仍按网站与关键词的稳定身份分别保存。费用按当前去重查询数预览，前100普通查询采用每词$0.006的保守上限，无额外付费选项；实际账本优先供应商实际成本。SERP单轮／月度预算与旧Labs试用预算独立。价格依据：[Google SERP官方价目表](https://dataforseo.com/pricing/google-serp/google-organic-serp-api)。

服务端按自然月第1期（1–15日）、第2期（16日至月末）建立唯一账本。预览绑定当前正式目标快照，目标变化须重新预览；同一期已有记录时只能查看或续跑原记录。持久任务标识、提交状态及预算预留用于阻止并发重复扣费；未知提交结果不自动重新POST。

响应未确认时保留UNKNOWN及预算预留，先核对供应商账单，不自动重试付费请求。结果已经收到但保存／解析失败时，仅从已存响应恢复；缓存重放不重新请求供应商。管理页展示每期状态、任务进度、实际成本／预留及预算。付费双闸关闭时，手动启动、续跑及定时任务都不能请求供应商。

连接、计划和结果接口只允许已登录的管理会话读取。已有Labs历史运行记录仍可下载规范化关键词及逐页记录，不含请求头或连接凭据。错误响应仅保留安全状态码，不返回密码、原始连接字符串或任意供应商报错内容。

## 数据口径

SERP实测保存指定地区、语言、设备、供应商任务ID、真实检查时间、Google结果链接及各自然结果的`rank_group`、`rank_absolute`和URL。`rank_group`作为自然名次；广告和其他搜索功能不混入关键词自然排名。来源为`dataforseo_serp`，不把历史Labs或GSC数据转换成SERP结果。

默认排名概览和关键词主表围绕相同正式目标统计实测进度；最近一次有效检查结果保留真实日期，不因超过7天清空。趋势按每月第1／2期的实际采集记录展示，未采集的期次留空；首次抓取前不画虚构趋势，不将旧GSC均值补作当天或本期实测。未完成的任务不计作成功核验，也不计为没有排名。

已有业务词以稳定身份匹配，保留正式目标、候选、模型保护和人工目标页面。供应商结果中的URL是实际排名页面，不自动替换目标页。完整取得前100自然名次且本站未出现，才标“暂无前100排名”；请求失败、深度不足、改写查询或待采集均保留待核验。排名下降不会删除关键词。候选不自动加入付费范围，新发现业务词先在词库筛检与核实页面。

Labs Ranked Keywords历史记录属于域名排名数据库，接口名live不代表当次抓Google。它的未返回、旧SERP日期和无数据，都不能证明本站当前没有排名。历史搜索量缺少真实月份时，不能作为“两个月无声量”的证据。

原始返回与规范结果保留在服务端请求记录；历史原始指标和审核证据可追溯。任何来源更新都不能重新应用固定历史审计、复活归档/归并或删除候选。

## 同词多页与核实结果

目标页面与实际排名页面分别保存，一个关键词可以有多个页面。目标页逐页检查HTTP状态、最终canonical及正文意图；每个新增匹配页都有独立证据。同次SERP采集的每个本站URL保存自己的自然名次；不把关键词最佳名次复制给其他页面。关键词摘要从同一轮有效结果中取最佳自然名次，关键词只计一次，页面数单独统计。历史Labs记录保留自己的来源日期，不与SERP混算。

逐词页面审计支持VERIFIED（已核实匹配，含additionalPages）、NO_MATCH（查过公开目录仍无匹配页）、MISSING（明确404/410）、CONTENT_GAP（页面存在但缺少目标意图内容）、MISMATCH（页面意图错配）、REVIEW（证据不足）。NO_MATCH必须记录核查目录、页面数、时间和具体检索结论；不能把未找到页面伪造成404。CONTENT_GAP保留检查页面作为内容优化线索。缺页、内容缺口及错配只调整页面状态，关键词继续保留；本轮已有待核实词应核成具体结论，不能靠重命名隐藏未核实工作。

每个关键词只展示一个排名区间标签：前10（1–10）、前30（11–30）、前50（31–50）、前100（51–100）。成功核验未检出才显示“暂无前100排名”；另列待采集／采集失败／深度不足，不混成一个“无排名”。

三张协作表继续由现有采集器每天北京时间10:30读取并增量提交；来源健康接口只展示已存行数、最近内容变化及已变更行的来源时间，不能证明每日完整运行成功。新词／变化逐词检查相关性、完成状态和页面，缺行不删除候选或目标。Vercel每日Cron检查来源健康及SERP计划到期状态；它不直接读取钉钉，付费双闸关闭时也不请求供应商。每日Codex采集器只维护三表与技术健康，不代替在线计划执行付费。

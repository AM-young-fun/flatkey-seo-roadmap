# 已优化关键词与手动抓取

入口统一在 `/keywords`，页面状态新增「已优化」，按关键词明细原有的去重、国家、排名区间与业务分类展示。独立「排名监控」导航与页面已移除，旧 `/monitor` 重定向至 `/keywords?status=optimized`。已优化状态来自「Flatkey keyword opt」已同步、已完成页面的关键词关联，独立于排名是否存在。旧同步未填写页面核验标记时也应显示；付费资格仍使用已有正式词页面审计，只有已核实与该页面精确关联的主词、辅助词参与抓取；暂无符合条件的词时按钮显示「待核对」，并直接展示关联词数量与缺少已核实正式词的原因；其他页面失败不会占用该页次数或改变资格。

「抓取排名」移入关键词行的操作列，点击提交该关键词关联优化页面的主词、辅助词在美国、日本、西班牙、巴西的前100自然结果任务。多个词关联同页时共享一个页面账本、每日额度和进度；同词有多个优化页面时逐页提供操作，不提供批量付费按钮。四国结果分别显示，切换国家不会重新收费。费用上限放在按钮 tooltip，执行沿用现有连接、余额检查、单次和月度预算以及紧急停止开关，独立于隔周自动采集开关。

每个页面北京时间每天最多一次新的付费提交，零点重置。失败或部分完成且有已接收的供应商任务编号时，可点击「重试取结果」，恢复原任务的免费 GET 取回；不创建新账本、不重发 POST、不增加费用，已成功的国家结果保留。未接收、结果不明和超过供应商30天保留期的任务不能伪装成免费重试。服务端规范化页面 URL 后生成稳定身份，以 `OPTIMIZED_PAGE + 日期 + 页面身份` 唯一账本和事务锁约束。刷新、重复点击、换浏览器、修改来源行编号都不能重新提交。一次只允许一个页面处于采集或结果不明状态。请求中断后仍占用当日次数；供应商接收结果不明时保留原账本核对，不自动重发。未发出请求且中断的账本由结果轮询关闭为失败，当日也不重发。

`GET /api/rankings/monitor` 只读取已存页面和采集结果，供关键词明细使用。手动页面抓取、隔周自动抓取和已有小批实测共用 SERP 证据，按供应商实际采集时间选取同页面、同词、同国最新的有效排名，并与前一次有效排名比较。手动结果不再固定优先，其他页面发起的同词同国实测也可复用；接口保留每个优化页自己的名次，明细按下文的关键词口径显示。排队、失败、纠词及覆盖不足且未命中的结果不覆盖已有有效排名；没有有效历史时仍保留本页手动任务状态。不会为展示数据自动收费。`POST` 仅支持严格的单页 `start`、原账本 `poll` 或免费 `retry`；不接受任意关键词、URL、国家、任务参数或批量身份。需要登录并校验请求来源。前端采集中每30秒读取原任务结果，页面刷新和结果轮询不会提交新的付费任务；关闭网页后可回到关键词明细继续接收原结果。

接口保留各优化页面自己的名次与历史比较。关键词明细沿用同站同词同国的最佳实际页面口径，选择手动、自动实测中更新的有效结果，同时更新名次、实际页面、采集时间和涨跌。单页未命中但本站其他页有排名时，关键词仍显示实际命中页面的排名；只有完整覆盖100个自然位置且本站未命中才标记关键词100外。深度不足、Google纠词、失败和未返回不视为下降。

提交请求开始后，操作按钮与排名变化列即显示「处理中」；排队、等待供应商结果和本地处理结果期间持续显示该状态，并展示已返回与待处理任务数量。已有名次标注为上次有效排名，等待本次完成后自动更新。处理中禁用重复抓取，刷新页面后按原账本恢复状态。任务完成、部分完成、失败、结果待核对分别展示，使用当日额度不再等同于完成采集。

手动页面账本不进入隔周期次趋势或周报比较，也不推进下次计划时间。复用现有数据库表，无新增迁移；新页面和接口需随项目发布后才在线生效。

验证不调用真实付费接口。供应商提交与原任务取回协议见 [DataForSEO 官方文档](https://docs.dataforseo.com/v3/serp/google/organic/task_post/)。

站内其他页面在覆盖不足的采集中仍有明确名次时，该正向实测可更新关键词的站内最佳排名和变化；未命中目标页不能据此推断目标页跌出前100。接口分别保留目标页与站内关键词的两次有效结果，浅层未命中不会挤掉目标页的历史名次。

全部国家视图逐国显示有效采集时间、名次变化和前后名次；本次覆盖不足且未命中时标注“本次未取得有效名次，保留历史排名”及尝试时间。实际排名页面优先展示最新采集的国家页面，旧国家结果可展开查看，避免数值最好的旧排名掩盖其他国家的新结果。

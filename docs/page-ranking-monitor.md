# 排名监控

入口 `/monitor`，只展示「Flatkey keyword opt」已同步、已完成并有发布核验证据的页面。同一页面的重复行、锚点和跟踪参数合并。正式词且已有核实页面关联的主词、辅助词才参与抓取；暂无符合条件的词时禁用按钮。

每页只有「抓取排名」按钮，不提供全选或批量操作。点击直接向 DataForSEO Google Organic Standard 提交该页关联词在美国、日本、西班牙、巴西的前100自然结果任务；四国结果分别显示，切换国家不会重新收费。费用上限放在按钮 tooltip，执行沿用现有连接、余额检查、单次和月度预算以及紧急停止开关，独立于隔周自动采集开关。

每个页面北京时间每天最多一次，零点重置。服务端规范化页面 URL 后生成稳定身份，以 `OPTIMIZED_PAGE + 日期 + 页面身份` 唯一账本和事务锁约束。刷新、重复点击、换浏览器、修改来源行编号都不能重新提交。一次只允许一个页面处于采集或结果不明状态。请求中断后仍占用当日次数；供应商接收结果不明时保留原账本核对，不自动重发。未发出请求且中断的账本由结果轮询关闭为失败，当日也不重发。

`GET /api/rankings/monitor` 只读取已存页面和最近两次采集。`POST` 仅支持严格的单页 `start` 或原账本 `poll`；不接受任意关键词、URL、国家、任务参数或批量身份。需要登录并校验请求来源。前端采集中每30秒读取原任务结果，页面刷新和结果轮询不会提交新的付费任务；关闭网页后可回到页面继续接收原结果。

名次对应该优化页面自己的自然位置，不借用本站其他 URL 的更好名次。每个词按同国、同页面比较最近两次采集，显示 `↑ N`、`↓ N`、持平、进入前100或跌出前100；第一次显示首次记录。只有完整覆盖100个自然位置后，未命中才标记100外；深度不足、Google纠词、失败和未返回不视为下降。其他命中页面和比较日期放在 tooltip。

手动页面账本不进入隔周期次趋势或周报比较，也不推进下次计划时间。复用现有数据库表，无新增迁移；新页面和接口需随项目发布后才在线生效。

验证不调用真实付费接口。供应商提交与原任务取回协议见 [DataForSEO 官方文档](https://docs.dataforseo.com/v3/serp/google/organic/task_post/)。

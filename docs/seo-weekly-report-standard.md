# Flatkey SEO 周报标准（2026-11-04）

每周五北京时间 10:10 整理。报告回顾上周五至本周四，注明真实截止日和覆盖；下一周优化清单使用本次周五起的工作周期。日报保留明细，周报先讲结果、原因证据和下一步。

周报统一使用两个连续的完整周期。本期是上周五到本周四，上一期是紧邻的前一个周五到周四，均含首尾 7 天。例如 2026-11-13 周报，本期为 11-06 至 11-12，对比 10-30 至 11-05。GA4 和 GSC 延迟时，保留原定周期并标记「待更新」。只有两个周期都有完整且同口径的来源数据才计算环比。

## 展示顺序

首屏：一句结论 → 自然搜索访问与注册 → 一张可切换趋势。下面是最多 5 项「本周优化清单」。搜索表现、页面贡献、关键词变化、技术异常和原始证据收进对应展开区。缺数据时仍交付已核实部分，并明确未完成项，不用大段通用SEO知识替代业务结论。

每周结论回答：本周SEO结果如何、变化主要来自哪里、有何证据、本周最该做哪几个动作。关键词优化优先级综合业务相关性、当前机会、竞争/意图匹配、工作量和数据新鲜度，不能只按搜索量排序。每月再复查长期增长、内容覆盖和技术趋势，避免每周对短期噪音过度调整。

## 本轮交付与后续数据能力

已接入预览：GA4访问/注册及日趋势、逐页GSC数据、页面分类、真实词库声量与站点排名、优化目标/首次基线及项目端版本化归档、周行动草稿及归档API。

仍需补充来源后才能完整自动判断：查询词×页面×国家级GSC证据、已核实排名URL、经过校准的排名CTR曲线、GSC索引/技术检查证据及付费收入事件。自动检查依据当次已获数据出结论，不把计划中的能力标成已采齐。
